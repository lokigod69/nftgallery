Currently jump-on-tap is only implemented in Room 1.

Resets:

Called on:

This prevents situations where the camera keeps drifting after exiting viewer mode.

5. Raycasting & Interaction Rules
To avoid “random NFT opens from behind the wall” and similar nonsense, the raycast pipeline is now stricter.

5.1. Distance gating
Constant defined in nft-viewer.js:

ts
Copy code
export const MAX_NFT_INTERACTION_DISTANCE = 35;
Applied in all rooms (1, 2, 4, 5), both desktop & mobile:

Run raycast against picturePlanes.

Take the closest hit (intersects[0]).

Require hit.distance <= MAX_NFT_INTERACTION_DISTANCE to allow interaction.

Effect:

You must be reasonably close to the wall/NFT to open it.

Taps/clicks from far away will be ignored (instead of randomly hitting something behind the user).

5.2. Front-facing normal filter
To avoid hitting backfaces or weird geometry:

For each hit, we compute alignment of the face normal vs direction from camera:

ts
Copy code
const worldNormal = hit.face.normal.clone().transformDirection(object.matrixWorld);
const camToHit = hit.point.clone().sub(camera.position).normalize();
const alignment = worldNormal.dot(camToHit.clone().multiplyScalar(-1));
If alignment < 0.5 → interaction is rejected as “not front-facing enough”.

Gating chain (both desktop & mobile):

Any intersections?

Front-facing enough? (alignment >= 0.5)

Is userData.isNFT === true?

hit.distance <= MAX_NFT_INTERACTION_DISTANCE?

If all pass → nftViewer.openByMesh(object).

6. Desktop Click Handler Normalization
Previously, Room 4 & 5 used a different handler structure than Rooms 1 & 2.

6.1. Final pattern (all rooms)
All NFT-enabled rooms now follow the lock-first pattern:

ts
Copy code
function handleNFTClick(event) {
  if (nftViewer && nftViewer.isOpen && nftViewer.isOpen()) return;

  // 1. Lock-first: if not locked, lock & exit
  if (!controls.isLocked && event.target === renderer.domElement) {
    controls.lock();
    event.preventDefault();
    event.stopPropagation();
    return;
  }

  // 2. Only raycast when already locked
  mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
  mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;
  raycaster.setFromCamera(mouse, camera);
  const intersects = raycaster.intersectObjects(picturePlanes, false);

  // 3. Apply NFT + distance + normal gating
  // 4. If valid → nftViewer.openByMesh(object)
}
Benefits:

Identical behavior across rooms.

Removes subtle differences that were causing mobile flakiness.

Simpler mental model:

First click → lock

Second click on NFT → open viewer
